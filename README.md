# Dashboard การควบคุมภายใน กฟน. ปี 2569

Dashboard ติดตามความก้าวหน้า **แผนการจัดวางระบบการควบคุมภายในและการประเมินการควบคุมด้วยตนเอง (CSA) ประจำปี 2569** ของการไฟฟ้านครหลวง

ที่มาของแผน: เอกสารแนบ 5.1_AP_แผนการควบคุมภายใน ปี 2569 (ปรับปรุงไตรมาส 2)

- **4 หมวดงานหลัก · 14 กิจกรรมย่อย** (ถ่วงน้ำหนักตามค่าที่ระบุในแผน รวม = 100)
- **ระยะดำเนินการ 12 เดือน:** ม.ค. – ธ.ค. 2569
- KPI · S-Curve (เป้าหมาย=ทอง / ผลจริง=เขียว) · กราฟแท่งรายหมวด · ตาราง Gantt รายกิจกรรมย่อย (ตัวเลขเป้าหมาย/ผลจริงรายเดือน) · การ์ดกิจกรรมย่อยที่ล่าช้ากว่าแผน · กล่องรายงานสรุปประจำเดือน

## การถ่วงน้ำหนัก

แต่ละกิจกรรมย่อยมีค่าถ่วงน้ำหนักตามที่ระบุไว้ในแผน (รวมทั้งหมด = 100 คะแนน) เช่น หมวด 1 = 20 (10+5+5), หมวด 2 = 25 (5+10+5+5), หมวด 3 = 20 (10+5+5), หมวด 4 = 35 (10+12+6+7)

**เป้าหมายรายเดือน** ของแต่ละกิจกรรมย่อยระบุไว้ตรงๆ ในแผน (ไม่ใช่คำนวณจากช่วงวันที่) — % ของหมวด = ค่าเฉลี่ยถ่วงน้ำหนักของเป้าหมายกิจกรรมย่อยในหมวดนั้น ณ เดือนที่เลือก

## วิธีอัปเดตผลงานจริงประจำเดือน

1. เปิด `IC2569_ฟอร์มกรอกข้อมูล.xlsx` → แท็บ **กรอกข้อมูล** → กรอกผลจริง % (0-100) ของกิจกรรมย่อยที่ถึงกำหนดแล้ว → แท็บ **สรุปรายเดือน** → พิมพ์สรุปภาพรวมของเดือนนั้น (ถ้ามี) → Save
2. ดับเบิลคลิก `อัปเดตข้อมูล.command` → แปลงเป็น CSV และ push ขึ้น GitHub อัตโนมัติ
3. เปิดเว็บดูผล (กด Cmd+Shift+R หนึ่งครั้งถ้ายังเห็นข้อมูลเก่า)

**เคล็ดลับ:** กรอกแบบสะสม — เดือนที่งานเสร็จแล้ว (100%) ให้คงค่า 100 ในเดือนถัดๆ ไปด้วย เดือนที่ยังไม่ถึงกำหนดปล่อยว่างไว้ได้ (เส้นผลจริงบน S-Curve จะไม่ยื่นเข้าเดือนที่ยังไม่มีข้อมูล)

## รูปแบบ CSV (`data/IC_Dashboard.csv`)

| คอลัมน์ | ความหมาย |
|---|---|
| `AID` | `An-0` = แถวหมวดหลัก, `An-m` = กิจกรรมย่อย (เช่น `A2-3` = ข้อ 2.3) |
| `ระดับ` | `หมวดหลัก` / `กิจกรรมย่อย` |
| `รายการงาน` | ชื่อ (เพื่อให้คนอ่านง่าย) |
| `ม.ค.69` … `ธ.ค.69` | คอลัมน์รายเดือน (12 เดือน) |

ค่าช่องรายเดือน: แถวหมวดหลักและกิจกรรมย่อย ใส่ **ตัวเลข % ผลจริงสะสม (0-100)** ทั้งคู่ — Dashboard คำนวณ % หมวดหลักเองจาก `build_data.py` (ค่าที่กรอกในแถวหมวดหลักของ Excel เป็นสูตรอ้างอิงให้ดูเฉยๆ)

แถวพิเศษ `SUMMARY` เก็บข้อความสรุปประจำเดือน (มาจากชีต "สรุปรายเดือน" ในฟอร์ม)
