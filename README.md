# Dashboard การควบคุมภายใน กฟน. ปี 2569

Dashboard ติดตามความก้าวหน้า **แผนการจัดวางระบบการควบคุมภายในและการประเมินการควบคุมด้วยตนเอง ประจำปี 2569** ของการไฟฟ้านครหลวง — ออกแบบตามแนวทาง/รูปแบบเดียวกับ [BCM-Dashboard](https://atomnet18-lang.github.io/BCM-Dashboard/)

- **5 หมวดงานหลัก · 19 กิจกรรมย่อย**
- **ระยะดำเนินการ 15 เดือน:** ม.ค. 2569 – มี.ค. 2570 (งานรายงานต่อเนื่องถึงต้นปี 2570)
- KPI · S-Curve · กราฟแท่งรายหมวด · ตาราง Gantt รายกิจกรรมย่อย (พร้อมผู้รับผิดชอบ) · popup รายละเอียดรายเดือน

## การถ่วงน้ำหนัก

แผน IC ไม่ได้ระบุน้ำหนัก จึงถ่วงน้ำหนัก**ตามจำนวนกิจกรรมย่อย** (รวม = 100%): หมวด 1 = 31% (6 ข้อ), หมวด 2 = 26% (5 ข้อ), หมวด 3 = 11% (2 ข้อ), หมวด 4 = 11% (2 ข้อ), หมวด 5 = 21% (4 ข้อ)

เป้าหมายสะสมรายเดือน (เส้นแผนใน S-Curve) คำนวณ**เชิงเส้นตามช่วงเวลาดำเนินการ**ของแต่ละกิจกรรมย่อย (ถ่วงน้ำหนักเท่ากันภายในหมวด) — แต่ละหมวดถึง 100% ที่เดือนสิ้นสุดของกิจกรรมย่อยรายการสุดท้าย

## วิธีกรอกผลงานจริง (`data/IC_Dashboard.csv`)

ใช้กลไกเดียวกับ BCM — export จาก Microsoft Lists / SharePoint แล้ววางทับไฟล์นี้ คอลัมน์:

| คอลัมน์ | ความหมาย |
|---|---|
| `AID` | `n-0` = แถวหมวดหลัก, `n-m` = กิจกรรมย่อย (เช่น `2-4` = ข้อ 2.4) |
| `Name` | ชื่อ (เพื่อให้คนอ่านง่าย — Dashboard ไม่ได้ใช้) |
| `Status` | `เสร็จสิ้น` / `อยู่ระหว่างดำเนินการ` / `ยังไม่ดำเนินการ` |
| `Note` | ความคืบหน้า (แสดงใต้ Gantt) |
| `Issue` | ปัญหา/แนวทางแก้ไข |
| `ม.ค.69` … `มี.ค.70` | คอลัมน์รายเดือน (15 เดือน) |

ค่าช่องรายเดือน:

- **แถวหมวดหลัก (`n-0`):** ใส่ `% สะสม` เช่น `45` หรือ `45 - รายละเอียดงานของเดือนนั้น` (คลิกดูใน popup)
- **แถวกิจกรรมย่อย (`n-m`):** ใส่ข้อความรายละเอียดงานของเดือนนั้น (จะมีจุดส้ม ● ให้คลิกดูบน Gantt)

> เริ่มต้นไฟล์ว่าง → Dashboard แสดงเฉพาะ "แผน" (เป้าหมาย/Gantt) และสถานะ "รอรายงานผล" จนกว่าจะมีข้อมูลจริง ลองเปลี่ยนชื่อ `IC_Dashboard.example.csv` เป็น `IC_Dashboard.csv` เพื่อดูตัวอย่างเส้นผลงานจริง

## เผยแพร่บน GitHub Pages (เหมือน BCM)

1. สร้าง repo เช่น `IC-Dashboard` แล้ว push ทั้งโฟลเดอร์นี้
2. Settings → Pages → Branch: `main` / root → Save
3. เปิด `https://<username>.github.io/IC-Dashboard/`
4. คัดลอก `logo.png` จาก BCM repo มาวางในโฟลเดอร์เพื่อให้โลโก้แสดง

อัปเดตผลงาน: เชื่อม Microsoft Lists → export CSV → commit ทับ `data/IC_Dashboard.csv` (Dashboard อ่านสด ไม่ต้องแก้โค้ด)
